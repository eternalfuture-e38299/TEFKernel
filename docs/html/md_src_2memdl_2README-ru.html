memdl - Библиотека динамической загрузки из памяти 📚

Введение 🚀

  • memdl - это кроссплатформенная библиотека на C, которая поддерживает загрузку общих библиотек (.so/.dll) непосредственно из данных в памяти без записи на физический диск. Она предоставляет API, подобный dlopen, но работает с данными библиотеки в памяти, а не с путями к файлам.

Основные возможности ✨

  • Истинная загрузка из памяти 🔄 - Некоторые платформы поддерживают чистую загрузку из памяти без создания физических файлов
  • Кроссплатформенная поддержка 🌍 - Windows, Linux, Android, macOS, iOS
  • Автоматическая стратегия отката 📉 - Автоматически использует временные файлы при сбое загрузки из памяти
  • Проверка формата 🔒 - Автоматически проверяет форматы ELF/Mach-O/PE

Подробности поддержки платформ 🏗️

Полный рабочий процесс

++

void* lib_data = load_library_to_memory();

// 3. Загрузка из памяти (автоматический выбор лучшего решения)
memdl_handle_t handle = memdl_open(lib_data, lib_size, MEMDL_NOW | MEMDL_LOCAL);
if (!handle) {
printf("❌ Сбой загрузки: %s\n", memdl_error());
return -1;
}
// 4. Использование функций библиотеки

Резюме 🎯

  • memdl обеспечивает оптимальную производительность на платформах, поддерживающих загрузку из памяти, и автоматически откатывается для обеспечения доступности на неподдерживаемых платформах. Разработчикам не нужно беспокоиться о деталях реализации, так как API остается последовательным.
