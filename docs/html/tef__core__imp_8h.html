◆ tpf_initialize_all_plugins()

bool tpf_initialize_all_plugins ( )

初始化所有已加载的插件并将其注册到所有共享库

这个函数会遍历所有已加载的插件，调用它们的初始化函数，并将所有插件的符号 注册到已注册的共享库中。这样可以确保所有插件都能互相访问彼此的API。

Returns
true 所有插件都成功初始化和注册
false 有一个或多个插件初始化或注册失败
